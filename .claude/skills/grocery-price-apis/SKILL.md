# API магазинів: Zakaz.ua і Сільпо

Код, який усе це реалізує, лежить у `backend/app/catalog/etl/`:
- `zakaz.py`, `silpo.py` — клієнти й парсери;
- `normalize.py` — GTIN, вага, ціна за кг, теги;
- `categories.py` — запити й правила відбору для канонічних категорій;
- `runner.py` — оркестрація.

Нове правило чи пастку спершу додай туди разом із тестом у `app/catalog/tests/`, а вже потім опиши тут.

Обидва API неофіційні: ними користуються сайти самих мереж, документації немає, ключ не потрібен. Усе нижче перевірено живими запитами 2026-11-21. Формат може змінитися без попередження. Сирі відповіді в БД не зберігаємо: одна сторінка пошуку важить 150–360 КБ, і нічний прогін з'їв би 500 МБ безкоштовного Supabase. Для налагодження парсера клади їх стиснутими файлами в `backend/data/raw/` (є в `.gitignore`), тоді після виправлення парсера дані не доведеться завантажувати знову.

Повні приклади відповідей лежать у `references/payloads.md`. Читай їх, коли пишеш парсер: там видно точні типи полів.

## Етикет запитів

- Не більше 4–5 паралельних запитів, пауза 0.2–0.3 с між сторінками. При 429/5xx — retry з backoff.
- **Zakaz.ua має ліміт запитів.** При повному прогоні по Києву (~6000 запитів) він почав відповідати 429 приблизно через хвилину, на магазинах Auchan, і тримав ліміт близько 2 хвилин. Через це 11 магазинів залишились без цін. Тепер `etl/http.py` на 429 ставить на паузу всі запити (з урахуванням `Retry-After`, експоненційно до 40 с). `runner` після паузи 60 с робить другий прохід лише по магазинах з помилками.
- Нейтральний `User-Agent` без особистих даних.
- Нічний ETL завантажує тільки потрібні категорії міста демо (Київ), а не весь каталог.
- Знімок даних лежить у репо: якщо API ляже на пітчі, демо працює з бази.

## Zakaz.ua (`https://stores-api.zakaz.ua`)

Заголовок `Accept-Language: uk`, щоб назви приходили українською.

| Що | Запит |
|---|---|
| Магазини (70, з них 56 продуктових) | `GET /stores/` → список; `id` (text), `retail_chain`, `name`, `city` (slug: `kiev`, `lviv`…), `address.coords.lat/lng`, `delivery_types`, `is_active` |
| Категорії магазину | `GET /stores/{id}/categories/` → дерево; id свої в кожній мережі (`dairy-and-eggs-auchan` → `curd-auchan`, у Novus `uht-milk`, `curd-without-additives-novus`) |
| Товари категорії | `GET /stores/{id}/categories/{cat}/products/?page=N` → `{count, results}` |
| Пошук | `GET /stores/{id}/products/search/?q=…&per_page=100&page=N` → `{count, count_available, results, …}` (`per_page` до 100) |
| Товар за EAN | `GET /stores/{id}/products/{ean}/` (EAN у форматі Zakaz, 14 цифр) → той самий товар в іншій мережі |

Поля товару:

| Поле | Тип / приклад | Пастка |
|---|---|---|
| `ean` | `"04820222760249"` | 14 цифр із нулем на початку. Нормалізуй (див. нижче) |
| `title` | `"Молоко Галичина ультрапастеризоване 2,5% 950г"` | вага є в назві |
| `price` | `7499` | **копійки** (74,99 ₴) |
| `discount` | `{status, value: 90, old_price: 33900, due_date: "2026-11-29"}` | `value` — відсоток. Акція ≥50% — кандидат у «товар-приманку» |
| `price_wholesale` | `[{min_qty: 2, price: 7124}, …]` | гуртові ціни Metro. Для звичайного кошика ігноруй |
| `weight` | `950.0` або `null` | грами. У яєць `null` або вага всієї упаковки, тому кількість штук бери з назви |
| `unit` | `"pcs"` / `"kg"` | `kg` = ваговий товар: `price` за кг, `weight` = null, `quantity` у грамах (`min: 500, step: 500`), а `ean` буває нецифровим (`"auchan02202760000000"`) |
| `in_stock` | `true` | ~11% результатів пошуку мають `false`, їх відкидай |
| `ingredients` | `["Молоко коров'яче…<br>"]` | список HTML-рядків. Іноді порожній |
| `nutrition_facts` | `{"ingredient_sugars": "4.70г", …}` | рядки з одиницями |
| `fat` | `"2.5%"` | |
| `producer.trademark` | `"Галичина"` | бренд, у тому числі власні марки мереж (`Auchan`, `Novus`, `Metro Chef`, `Marka Promo`) |
| `category_id` | `"uht-milk"` | категорія конкретної мережі |
| `img.s350x350` | URL | є також `s150x150`, `s200x200` |
| `web_url` | URL товару на `<chain>.zakaz.ua` | для кнопки «замовити» |

Магазини Zakaz — це DRIVE-точки онлайн-замовлення в реальних гіпермаркетах. Їх мало: у Києві Auchan 8, Novus 4, Metro 3, Ultramarket 3, Megamarket 3, ЕКО 2. Ціни й наявність прив'язані до `store_id`.

## Сільпо (`https://sf-ecom-api.silpo.ua/v1/uk`)

| Що | Запит |
|---|---|
| Магазини (464) | `GET /branches?limit=100&offset=N` → `{total, items}`; `branchId` (uuid), `externalId` (номер магазину), `cityFull`, `addressFull`, `latitude`/`longitude` (**рядки**, один магазин без координат), `hasPickup`, `open`, `schedules` |
| Товари | `GET /branches/{branchId}/products?limit=60&offset=N&deliveryType=DeliveryHome&search=…&includeChildCategories=true&sortBy=productsList&sortDirection=desc` → `{limit, offset, total, items}` |
| Картка товару | `GET /branches/{branchId}/products/{slug}` → `barcodes`, `attributeGroups`, `media` |

- **Ціни й залишки залежать від `branchId`.** Наприклад, «Галичина Українське 870 г» коштує 55,99 ₴ в одному київському магазині і 59,99 ₴ в іншому. 77 із 464 точок повертають 0 товарів або позначені `delete_filia_…`: у них немає онлайн-каталогу, тож вважай їх недоступними для порівняння. Перевірений список (387 філій із каталогом) лежить у `docs/stores.md` / `docs/stores.csv`. Гілка `00000000-0000-0000-0000-000000000000` — це каталог за замовчуванням, а не конкретний магазин.
- Поля списку: `title` (**без ваги**), `displayPrice` (гривні, float), `displayOldPrice`, `displayRatio` (`"950г"`, `"1кг"`, `"10шт"`, `"6шт/уп"`), `weighted`, `stock` (відсутні товари пошук не повертає), `brandTitle`, `slug`, `icon`. Пошук приймає `limit` до 100.
- **Вагові товари (`weighted: true`, `ratio: "кг"`):** `price` — це ціна за кг (банан 87.35), а `displayPrice` — за 100 г (8.74, `displayRatio: "100г"`). `stock` тут у кг і дробовий (185.2).
- **EAN у списку немає**, він є лише в картці. `barcodes` — це суміш GTIN-13, GTIN-14 і внутрішніх кодів магазину, що починаються з `02`.
- **Склад майже завжди порожній.** Блоки `ingredients` і `composition` в `attributeGroups` зазвичай не заповнені, є лише `nutrient`. Склад, який не вдалося перевірити, вважай **невідомим, а не чистим**. Його можна взяти зі Zakaz за тим самим GTIN.
- Фото: `https://images.silpo.ua/products/300x300/{icon}` (є також `500x500/webp/{icon}`). Сторінка товару `https://silpo.ua/product/{slug}` віддає curl'у 403 (захист від ботів). У браузері не перевірено.

## Нормалізація

- **GTIN:** прибрати нулі на початку, доповнити до 13 цифр (`"04820222760249"` → `"4820222760249"`). 14-значні GTIN лиши як є. Коди з префіксом `02` не використовуй для зведення між мережами: це внутрішні коди.
- **Вага пачки:** спершу назва (Zakaz) або `displayRatio` (Сільпо), потім поле `weight`. Регулярні вирази мають покривати `950г`, `1,5 кг`, `0.9 л`, `2х200г` / `2x200 г` (мультипак = 400 г), `10шт`, `6шт/уп`. Одиниці зводь до `g`, `ml`, `pcs`. Для рідин рахуй 1 г ≈ 1 мл: молоко обидві мережі вказують у грамах.
- **Ціна за одиницю:** `unit_price = price / pack_qty * 1000` (₴/кг або ₴/л), а для `pcs` — `price / pack_qty` (₴/шт).
- **Скільки пачок купити:** `packs = ceil(need / pack_qty)`, вартість = `packs * price`. Для 500 г сиру 3 пачки по 200 г бувають дешевші за 2 по 350 г.
- **Теги складу** визначаються правилами по тексту `ingredients`, без LLM:
  - `sugar`: «цукор|цукру|сироп|глюкоз|фруктоз|декстроз». Спершу видали заперечення «без (доданого|додавання) цукру».
  - `palm_oil`: «пальм|рослинн… жир|замінник молочного жиру|ЗМЖ».
  - Для «без цукру» не використовуй `nutrition_facts.sugars`: у молоці 4.7 г природної лактози, і такий фільтр його помилково відсіє.

## Пастки, знайдені на реальних даних

- Пошук «сир кисломолочний» повертає і сир з добавками («зі сметаною та курагою»), і дитячий. Фільтруй `\s(з|зі|із)\s`, `для дітей`.
- «Кава мелена» повертає ароматизовану («Марципанова»), без кофеїну, дріп-пакети й капсули. Їх треба відсіяти, інакше кошик стає дешевшим нечесно.
- Яйця С2/С3 дрібніші за С1/С0. Порівнювати їх за ціною за штуку некоректно, тому враховуй категорію яєць як атрибут.
- Акція −90% (Jacobs Kronung Espresso 200 г у Novus, 339 → 33,99 ₴ до 29.11) одна робить кошик мережі найдешевшим. Це варто показувати в `warnings`.
- Той самий EAN коштує в різних мережах дуже по-різному: Jacobs Gold 250 г — від 159 ₴ (Сільпо) до 339 ₴ (Ultramarket).

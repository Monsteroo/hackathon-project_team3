# 🎨 Sayvy MarTech Pipeline

Автоматизований пайплайн генерації маркетингових креативів для A/B-тестування гіпотез залучення:
1. **AI-генерація чистих рекламних сцен без тексту** на орендованих GPU у RunPod Community Cloud (`SG161222/RealVisXL_V5.0`).
2. **Локальна верстка та локалізація** у 3 форматах (`1080×1080`, `1080×1920`, `1200×628`) у фірмовій дизайн-системі **Sayvy** (`#111114` графіт + `#C6F432` лайм, шрифти `Onest` / `Inter`) через Headless Chrome.

> **Готові 90 банерів + `manifest.csv`:** [Google Drive (`hackathon-project_team3`)](https://drive.google.com/drive/folders/1tlN3K2Z2RxFZ3zpuHarb2sdPPgqQMAdf)

---

## 📁 Структура

- `campaign.json` — конфіг кампанії: бренд-токени, формати та 30 сцен із текстами (6 гіпотез × 5 сцен).
- `runpod_generate.py` — піднімає найдешевшу вільну Community GPU (`>= 16 GB VRAM`), генерує базові сцени в `/assets/scenes/` та автоматично видаляє Pod у блоці `finally:`.
- `render_creatives.py` — рендерить 90 банерів у `/output/<locale>/<format>/` та формує `/output/manifest.csv` для аналітики A/B-тестів.

---

## 🧪 Покриті гіпотези (6 × 5 = 30 сцен)

1. `H1_price_spread` — розкид цін 15–32% між супермаркетами (~97.50 грн переплати на базовому кошику).
2. `H2_shrinkflation` — прихована шрінкфляція (`870 г` vs `950 г`) і чесна ціна за 1 кг.
3. `H3_voice_intent` — перетворення голосового або текстового запиту (*«все на сирники»*, *«борщ»*) на готовий кошик за 10 секунд.
4. `H4_private_labels` — розумні аналоги та власні торгові марки без переплати за бренд.
5. `H5_geo_smart_split` — баланс «ціна vs відстань» і 3 сценарії покупки (найближчий, найвигідніший, Smart Split).
6. `H6_unit_economics_offer` — офер 4-денного тріалу та окупність підписки \$3.99/міс (~165 грн) із 1–2 походів.

## 🚀 Як запустити повторно

1. Додайте `RUNPOD_API_KEY` у кореневий `.env` (див. [../.env.example](../.env.example)).
2. Згенеруйте сцени (пропускає вже існуючі в `/assets/scenes/`):
   ```bash
   python3 martech/runpod_generate.py
   ```
   *(Тестовий прогін 30 сцен на `NVIDIA RTX A4000` ($0.17/год) зайняв 6.19 хв і коштував **~$0.0175**).*
3. Відрендеріть усі формати та `manifest.csv` (потрібен Google Chrome):
   ```bash
   python3 martech/render_creatives.py
   ```
